# E-commerce sales report
Gruppuppgift i Pythonprogrammering och statistisk dataanalys om e-handelsförsäljning.

Vi har skapat en körbar notebook som svarar på alla av ledningens frågor utifrån den data som fanns i ecommerce_sales.
Vi använde pandas för att importera och arbeta med datan och skrev de funktioner som behövdes för att kunna svara på ledningens frågor. Vi använde oss av branches och pull requests för att se till att så att allt gick att köra innan vi sammankopplade det till main.

## Python-version: 3.14

## För att köra koden själv:

### 1. Klona projetet
git clone https://github.com/Jujbraga/ecommerce-sales-report.git

### 2. Skapa och aktivera virtuell miljö
python -m venv .venv

### 3. För Windows PowerShell
.venv\Scripts\Activate
#### För macOS/Linux
source .venv/bin/activate

### 4. Installera beroenden
python -m pip install -r requirements.txt
